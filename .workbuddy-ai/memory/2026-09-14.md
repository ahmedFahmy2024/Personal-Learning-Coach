# 2026-09-14

## Milestone 0 — Foundation (Learning Coach)

Built the static Learning Coach shell, replacing the Next.js starter page.

- `src/lib/types.ts` — `StudyPlan`, `Quiz`, `QuizQuestion`, `QuizAnswer`,
  `QuizResult`, plus `ChatMessage` and `LearningSession`.
- `src/lib/storage.ts` — versioned `localStorage` (`learning-coach.session.v1`)
  with hand-written runtime guards; returns a notice instead of throwing.
- `src/lib/sample-data.ts` — deterministic sample session (Spanish preterite
  plan + 5-question quiz + scored result) with fixed timestamps.
- `src/lib/format.ts` — hand-written UTC timestamp/duration formatters.
- `src/components/*` — header, timeline, empty state, composer, context panel,
  study-plan panel, quiz-result panel, topic form, reset dialog, status notice.
- `src/components/learning-coach.tsx` — the single `"use client"` island owning
  all browser state.
- `src/app/globals.css` — design tokens from `docs/ui-spec.md` mapped through
  `@theme inline`.
- `docs/ui-spec.md` — updated for the active-topic control in the context panel
  and the reset-restores-sample behaviour.

Decisions worth remembering:

- Milestone 0 does **not** include interactive quiz answering or scoring; that
  belongs to Milestone 2 with the typed score tool. The quiz panel renders a
  stored, pre-graded result.
- Submitting a message schedules a local placeholder reply after 600 ms
  (`LOCAL_REPLY_DELAY_MS`) purely so the sending/appended states are
  demonstrable. Milestone 1 replaces the timer with the real streamed response.
- The initial session has an empty timeline but populated panels, so the empty
  state is the real entry point while the panels stay demonstrable.

Verified: `pnpm exec tsc --noEmit`, `pnpm lint`, `pnpm build` all clean. Also
checked the SSR HTML over HTTP and confirmed the Tailwind token utilities
compile. No browser automation was available, so interactions were not
exercised end to end.
