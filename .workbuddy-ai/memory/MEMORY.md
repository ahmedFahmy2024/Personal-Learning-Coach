# Learning Coach — project memory

Durable facts about this repository. Product and architecture decisions live in
`docs/`; this file only records conventions and toolchain gotchas that are not
owned by a source-of-truth document.

## Toolchain

- Next.js **16.3.5** (Turbopack), React **19.2.8**, Tailwind CSS **v4.3.3**,
  Biome **2.4.2**, pnpm. `next.config.ts` has `reactCompiler: true`.
- Route prop types are **global helpers generated by Next.js**:
  `LayoutProps<"/">`, `PageProps<"/...">`. They are declared in
  `.next/types/routes.d.ts`, which `next-env.d.ts` imports. Consequence:
  `pnpm exec tsc --noEmit` only passes after a `next dev`, `next build`, or
  `next typegen` run has generated that file.
- Inspect dependencies with `opensrc` (installed at the npm global prefix).
  `opensrc path --cwd . <pkg>` clones the upstream repo on a cache miss and can
  take minutes the first time — give it a long timeout rather than assuming it
  failed.

## Tailwind v4 gotchas

- Preflight applies `margin: 0` to `*`, which breaks the native `<dialog>`
  centring. A `<dialog>` needs an explicit `m-auto`.
- Design tokens live in `src/app/globals.css` as CSS custom properties, mapped
  into utilities through `@theme inline` (`--color-surface` → `bg-surface`,
  `--radius-card` → `rounded-card`). Dark mode switches the `:root` variables
  inside a `prefers-color-scheme` media query.
- `border-border` must be written explicitly: v4 defaults the border colour to
  `currentColor`, not to a theme colour.

## Server/client boundary

- `src/components/learning-coach.tsx` is the **only** file with `"use client"`.
  Every other component is imported into that client module graph and stays
  directive-free. Keep it that way.
- `src/app/page.tsx` is a Server Component; it builds the sample session and
  passes it to the island as a serializable prop.
- Reading `localStorage` during render would break server/client markup parity.
  The restore runs in an isomorphic layout effect so the saved session is
  applied before paint — no hydration mismatch and no flash of sample data.
- Format timestamps with the hand-written formatter in `src/lib/format.ts`, not
  `Intl.DateTimeFormat`: ICU data differs between Node and the browser, which
  shows up as a hydration mismatch.

## Persistence

- One versioned envelope key: `learning-coach.session.v1`
  (`src/lib/storage.ts`). Bump `STORAGE_VERSION` and add a migration when the
  persisted shape changes.
- Stored values are validated field by field with hand-written guards before
  they reach React state. No schema library was added; the shapes are small and
  `AGENTS.md` prefers the installed packages.
- Only user-made changes are written, so a pristine sample session is never
  persisted and a reset leaves storage genuinely empty.

## Checks

Run from the repository root: `pnpm exec tsc --noEmit`, `pnpm lint`,
`pnpm build`. `biome check` includes the formatter, so run
`pnpm exec biome check --write .` before `pnpm lint` or the formatter diffs fail
the check.
